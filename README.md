# GamingWeb

## Descripción del proyecto

GamingWeb es una página web de ejemplo dedicada a presentar información sobre videojuegos. Está construida con HTML5 semántico y CSS externo, usando Flexbox para el diseño. El objetivo principal es ofrecer una estructura limpia y coherente con una apariencia elegante y moderna.

## Estructura de carpetas

- `index.html` - Página principal con la estructura semántica y contenido de la web.
- `styles.css` - Estilos externos que definen el diseño oscuro y elegante de GamingWeb.

## Prompts utilizados durante el desarrollo

1. "Haz la estructura de un sitio web con las siguientes caracteristicas: - Uso de HTML5 semántico (header, nav, main, section, footer) - Uso de CSS externo - Uso de Flexbox - Inclusión de imágenes, enlaces y formulario - Diseño ordenado y coherente. Solo la estructura (esqueleto) de la pagina web"
   - Se usó para generar el HTML y CSS inicial del sitio web.

2. "El repositorio debe incluir mínimo 4 ramas, estos son los nombres: - main - develop - feature/estructura - feature/estilos"
   - Se usó para inicializar Git en el proyecto y crear las ramas necesarias.

3. "Quiero que la pagina web sea sobre datos sobre videojuegos, necesito que cambies el estilo de la pagina a una más elegante. Y el nombre de la pagina web sera \"GamingWeb\""
   - Se usó para actualizar el contenido y el estilo de la página con una temática de videojuegos y un diseño más elegante.
